## 이 책에 대하여

이 책은 **Claude Certified Architect – Foundations** 자격증 취득을 목표로 하는 모든 분들을 위해 쓰여졌습니다.

AI가 단순한 도구를 넘어 **생각하고 행동하는 에이전트**로 진화하고 있는 지금, Claude를 활용한 아키텍처 설계 능력은 개발자와 솔루션 아키텍트에게 필수적인 역량이 되었습니다.

이 책은 단순히 시험을 통과하기 위한 암기 자료가 아닙니다. **실제 프로덕션 환경에서 Claude를 활용하는 방법**, **멀티에이전트 시스템을 설계하는 원리**, **MCP를 통해 외부 세계와 연결하는 기술**을 처음부터 차근차근 이해할 수 있도록 설계했습니다.
