# 4.1 에이전트란 무엇인가?

> 📅 2026년 04월 05일 기준

---

## 에이전트 정의

```
에이전트 = LLM + 도구 + 루프

일반 LLM:  질문 → 답변 (한 번)
에이전트:  목표 → 계획 → 행동 → 관찰 → 반복 → 완료
```

---

## 에이전트 vs 일반 LLM

| 특징 | 일반 LLM | 에이전트 |
|------|---------|---------|
| 상호작용 | 단일 요청/응답 | 반복적 추론 |
| 도구 사용 | 없음 | 외부 툴 호출 |
| 자율성 | 없음 | 목표 달성까지 자율 실행 |
| 상태 | 없음 | 세션 내 상태 유지 |

---

## 에이전트의 핵심 구성 요소

```python
에이전트 = {
    "두뇌": Claude 모델 (추론 담당),
    "손": 도구들 (실제 행동 담당),
    "기억": 메시지 히스토리 (상태 유지),
    "루프": 목표 달성까지 반복
}
```

---

## 에이전트가 적합한 상황

```
✅ 에이전트 사용:
- 여러 단계를 거쳐야 하는 작업
- 외부 데이터가 필요한 작업
- 결과에 따라 다른 행동이 필요한 작업

❌ 일반 LLM으로 충분:
- 단순 Q&A
- 텍스트 번역
- 요약
```

---

## ARIA의 에이전트 역할

ARIA는 에이전트로서:
1. 업무 요청 이해
2. 필요한 정보 수집 (툴 사용)
3. 작업 실행
4. 결과 검증 및 보고
