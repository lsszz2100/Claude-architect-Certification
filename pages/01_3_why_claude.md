# 1.3 Claude가 특별한 이유

> 📅 2026년 04월 05일 기준

---

## Claude의 핵심 특징

### 1. 안전성 우선 설계

Anthropic의 Constitutional AI(CAI):
- 원칙 기반 학습
- 해로운 출력 최소화
- 투명성과 정직성

### 2. 긴 컨텍스트 윈도우

```
Claude Opus 4.6: 1,000,000 토큰
Claude Sonnet 4.6: 1,000,000 토큰
Claude Haiku 4.5: 200,000 토큰

참고: 1M 토큰 ≈ 책 750권
```

### 3. 강력한 코드 능력

- 코드 생성, 리뷰, 디버깅
- 여러 언어 지원
- Claude Code로 IDE 통합

### 4. 에이전트 친화적 설계

- tool_use 기능으로 외부 시스템 연결
- MCP 표준 프로토콜 지원
- 멀티에이전트 오케스트레이션

---

## Claude와 다른 모델 비교

| 특징 | Claude | 경쟁사 |
|------|--------|--------|
| 안전성 | Constitutional AI | 다양한 방식 |
| 컨텍스트 | 최대 1M 토큰 | 모델별 다름 |
| Claude Code | 전용 IDE 통합 | 일부 지원 |
| MCP | 표준 프로토콜 | 독자 방식 |

> ⚠️ 다른 모델 비교는 시험 범위 밖입니다. Claude의 특징만 집중하세요.

---

## 아키텍트로서 Claude 선택 기준

```
용도                           추천 모델
──────────────────────────────────────────
복잡한 추론, 연구 보고서       → Opus 4.6
균형 잡힌 일반 작업            → Sonnet 4.6
빠른 처리, 비용 효율           → Haiku 4.5
```
