---

## LLM의 핵심 원리

### 다음 토큰 예측

LLM의 기본 원리는 단순합니다:

```
입력: "서울은 대한민국의"
출력: "수도입니다" (가장 확률 높은 다음 토큰)
```

하지만 이 단순한 원리로 놀라운 능력이 나타납니다:
- 코드 작성
- 논리적 추론
- 창의적 글쓰기
- 질문 답변

### 토큰이란?

```
"Hello, World!" = ["Hello", ",", " World", "!"]  ← 4 토큰
"안녕하세요"    = ["안녕", "하세요"]              ← 2 토큰 (대략)

1 토큰 ≈ 영어 단어 0.75개
1 토큰 ≈ 한국어 음절 1-2개
```

## Transformer 아키텍처 (개요만)

> 시험에는 내부 구조 상세가 나오지 않습니다. 개념만 이해하세요.

```
핵심 혁신: Attention 메커니즘
- 문장 전체를 한 번에 볼 수 있음
- 단어 간 관계를 학습
- 병렬 처리 가능 → 빠른 학습
```

---

## LLM의 능력과 한계

### 능력
- 자연어 이해 및 생성
- 코드 생성 및 디버깅
- 번역 및 요약
- 추론 및 분석

### 한계
- 훈련 데이터 이후 정보 없음 (Knowledge cutoff)
- 수학적 계산 오류 가능
- 환각(Hallucination): 없는 사실 생성
- 컨텍스트 윈도우 제한

---

## LLM과 에이전트의 차이

```
LLM:    질문 → 답변 (1번)
에이전트: 질문 → 생각 → 툴 사용 → 관찰 → 생각 → 답변 (여러 번)
```

Claude는 단순 LLM을 넘어 에이전트로 동작할 수 있습니다.
