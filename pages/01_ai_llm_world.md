## 1.1 인공지능의 역사와 현재

### AI의 세 번의 봄

인공지능의 역사는 세 번의 큰 파도로 이루어져 있습니다.

1차 AI 붐 (1950~1970년대)  
Alan Turing의 "기계는 생각할 수 있는가?"라는 질문에서 시작되었습니다. 이 시기에는 규칙 기반 시스템과 논리 프로그래밍이 주류였습니다.

2차 AI 붐 (1980~1990년대)  
전문가 시스템(Expert Systems)의 등장. 의료 진단, 법률 자문 등에 적용되었으나 지식 입력의 한계로 침체기를 맞이합니다.

3차 AI 붐 (2010년대~현재)  
딥러닝의 혁명. AlphaGo의 바둑 정복(2016), GPT 시리즈, 그리고 Claude의 등장으로 이어집니다.

## 1.2 Large Language Model이란?

### 언어 모델의 본질

LLM(Large Language Model)은 "다음 단어를 예측하는 기계" 로 시작합니다.

```
입력: "서울의 수도는"
예측: "서울" (?) → 아니면 → "한국의 수도는 서울입니다"
```

수조 개의 텍스트를 학습하면서, 단순한 단어 예측이 언어 이해와 추론으로 발전했습니다.

### LLM이 할 수 있는 것

| 능력 | 예시 |
|------|------|
| 텍스트 생성 | 이메일 초안, 보고서 작성 |
| 코드 작성 | Python, JavaScript, SQL |
| 추론 | 수학 문제, 논리 퍼즐 |
| 번역 | 100개 이상의 언어 |
| 요약 | 긴 문서를 핵심만 추출 |
| 분류 | 감정 분석, 스팸 탐지 |

### LLM의 한계

- 환각(Hallucination): 없는 사실을 만들어낼 수 있음
- 컨텍스트 제한: 처리할 수 있는 텍스트 길이에 한계
- 최신 정보 부재: 학습 데이터 기준 이후의 정보는 모름
- 결정론적이지 않음: 같은 질문에 다른 답변 가능

> 💡 이러한 한계를 극복하기 위해 Tool Use와 에이전틱 시스템이 등장했습니다!

## 1.3 Claude가 특별한 이유

### Anthropic의 철학: Constitutional AI

Claude는 단순히 "좋은 AI"를 만드는 것이 아니라 "안전하고 신뢰할 수 있는 AI" 를 목표로 합니다.

Anthropic은 Constitutional AI(헌법적 AI) 라는 접근법을 사용합니다:
- AI가 스스로 자신의 응답을 평가하고 수정
- 명확한 원칙(Constitution)을 기반으로 훈련
- 인간의 피드백을 통한 지속적 개선

### Claude vs 다른 AI 모델

| 특성 | Claude | 경쟁 모델 |
|------|--------|-----------|
| 안전성 | Anthropic의 AI Safety 연구 기반 | 다양한 접근 |
| 정직성 | 모름을 명확히 인정 | 경우에 따라 다름 |
| 컨텍스트 창 | 1M tokens (최대) | 모델마다 다름 |
| 엔터프라이즈 | SOC II, HIPAA 지원 | 모델마다 다름 |
| 툴 사용 | 네이티브 지원 | 네이티브 지원 |

### Claude가 프로덕션에 강한 이유

```
✅ 낮은 환각률
✅ 긴 문서에서도 정확성 유지
✅ Jailbreak 저항성
✅ 엔터프라이즈급 보안 (SOC II Type 2, HIPAA)
✅ AWS, GCP, Azure 모두 지원
✅ 저작권 보호
```

## 📝 챕터 요약

- LLM은 텍스트 패턴 학습을 통해 추론, 코드 작성, 분류 등 다양한 작업 수행
- Claude는 안전성과 신뢰성을 핵심 가치로 하는 Anthropic의 모델
- 환각, 컨텍스트 제한 등의 한계는 Tool Use와 에이전트로 극복
- Claude의 1M 토큰 컨텍스트 창은 대규모 문서 처리에 강력한 장점
