## AI의 세 가지 파도

### 1차 파도: 규칙 기반 AI (1950-1980년대)

```
특징: 인간이 규칙을 직접 작성
예시: 체스 프로그램, 전문가 시스템
한계: 현실 세계의 모든 규칙을 코드로 표현 불가
```

대표 사건: 1956년 다트머스 학회 — AI라는 단어 탄생

### 2차 파도: 머신러닝 (1990-2010년대)

```
특징: 데이터에서 패턴을 학습
예시: 스팸 필터, 추천 시스템, 이미지 인식
한계: 대량의 레이블 데이터 필요, 특징 추출이 어려움
```

대표 사건: 2012년 AlexNet — 딥러닝의 부상

### 3차 파도: 대형 언어 모델 (2017-현재)

```
특징: 자연어로 광범위한 작업 처리
예시: GPT, Claude, Gemini
특징: 프롬프트만으로 새 작업 즉시 수행
```

대표 사건: 2017년 "Attention Is All You Need" 논문 — 트랜스포머 탄생

```

  ↓           ↓          ↓
인터넷  +   GPU/TPU  +  트랜스포머
                          ↓
                    현대 LLM
```
